# 推开世界的窗 (Breathe Window)

一个专为备考者、独处者设计的极简每日网页。推开一扇窗，望见地球某个角落此刻的景色与故事，然后关上窗，在手账留下印迹，继续前行。

---

## 设计理念

1. **轻量与聚焦**：每天只开一次，开窗可见五条内容（世界一角、科学自然、他人在场、思想火花、旧物新看），看完关窗，明天再来。
2. **极简美学**：纸张背景、人文衬线字体，配合呼吸式灯条、渐显交互，提供沉浸舒缓的"呼吸"空间。
3. **离线优先**：所有内容来自本地画册数据库，无需联网或 API 密钥，即开即用。

---

## 快速开始

本项目同时支持 **Python 3（零依赖）** 和 **Node.js (Express)** 两种运行方式。

### 方式 A：Python 3（推荐）

```bash
python3 server.py
```

macOS / Linux 下无需安装任何额外依赖，即开即用。

### 方式 B：Node.js

```bash
npm install
npm run dev
```

### 访问网页

打开浏览器访问 [http://localhost:3000](http://localhost:3000)。

- 在门槛页点击 **推 开 窗** 开始今天的旅行。
- 内容生成后自动锁定在本地 `localStorage`，当天重复刷新或访问将直接展示已保存内容。
- 阅读完五条内容后点击 **关 上 窗**，完成今日打卡，明天解锁。

## 功能说明

### 门槛页（开窗前）

- **拟物化双扇木窗**：每个城市配有独特窗框风格（京都深胡桃木、巴黎白橡木、圣托里尼纯白蓝框等）。
- **城市徽章**：显示当前城市名称及已探访状态（首次探访前为虚线圆圈，探访后显示红色 ✓ 邮戳）。
- **换一扇窗**：切换到下一座城市，7.5 秒动画演绎"UI 坍缩入地球→地球旋转飞越→新城市展开"的完整过程。
- **首页半球地球仪**：页面底部浮现的世界地图球面，实时标记当前城市位置，已探访城市用彩色脉冲点亮。

### 内容阅读页（开窗后）

每次开窗展示五张卡片，对应五个内容频道：

| 频道 | 内容类型 |
|------|----------|
| 世界一角 | 当地地标或街景故事 |
| 科学自然 | 当地生态、地理或自然现象 |
| 他人在场 | 当地居民的日常生活剪影 |
| 思想火花 | 与当地文化相关的思想或哲理 |
| 旧物新看 | 当地传统工艺、器物或历史物件 |

- 单页翻卡模式，含图片预加载骨架屏。
- 阅读进度自动存入 `localStorage`，刷新后可从上次停留处继续。

### 旅行手账（右上角"印迹"按钮）

点击右上角悬浮的 **印迹** 按钮打开侧边抽屉，含两个视图：

**地图印迹**
- 交互式世界地图，标记全部 300 座城市的坐标点。
- 已探访城市高亮显示（彩色脉冲点 + 所属国家地图填色）。
- 支持城市/国家名称搜索，以及按亚洲、欧洲、美洲、非洲/大洋洲过滤。
- 悬停显示城市名称、探访次数与最近探访日期。
- 点击未探访城市可快捷切换主界面的目标城市。
- 点击已探访城市可回顾该次旅行内容。

**印章手账**
- 卡片格子式布局，每次开窗留下一枚带城市特色色彩与 Emoji 的墨水邮戳。
- 点击邮戳卡片可重新阅读该次旅行内容（不消耗今日配额）。

### 关窗打卡仪式

阅读完五条内容后点击"关 上 窗"，触发明信片打卡弹窗：

- 呈现当次旅行的城市邮戳（含日期、开窗序号）。
- 自动将本次旅行记录存入 `localStorage` 历史。
- 仪式结束后平滑返回门槛页，今日窗口关闭。

## 项目结构

```
breathe-window/
├── server.py              # Python 3 零依赖服务端（推荐）
├── server.js              # Node.js/Express 服务端
├── package.json
├── public/
│   ├── index.html         # 前端单文件（含全部 CSS + JS）
│   └── assets/
│       ├── data/
│       │   ├── catalog.json        # 300 城市 × 5 条内容画册
│       │   ├── locations.json      # 城市元数据（坐标、窗框色、邮戳色等）
│       │   ├── window-themes.css   # 各城市窗框样式（由脚本生成）
│       │   └── world-map.min.svg   # 世界地图 SVG
│       └── images/
│           └── loc_*.png           # 各城市专属插画（每城市最多 5 张）
└── scripts/
    ├── verify_project_data.py      # 验证数据完整性
    ├── bulk_image_generator.py     # 批量生成城市插画
    ├── generate_window_css.py      # 从 locations.json 生成窗框 CSS
    ├── mark_custom_locations.py    # 标记城市的 hasCustomImages 字段
    ├── merge_catalog.py            # 合并新内容到画册
    └── centroids.json              # 国家地图几何中心坐标（供地图定位使用）
```

## 本地存储结构

所有数据存储在浏览器 `localStorage`，无需后端数据库：

| Key | 内容 |
|-----|------|
| `breathe:isOpen` | 今日是否已开窗（`"true"` / 不存在） |
| `breathe:items` | 今日五条内容（JSON 数组） |
| `breathe:currentSlideIndex` | 当前阅读进度（第几张卡片） |
| `breathe:currentLocationIndex` | 上次选择的城市索引 |
| `breathe:history` | 所有旅行历史记录（JSON 数组，最新在前） |

## 扩展画册数据

### 新增城市内容

在 `public/assets/data/catalog.json` 中按如下格式添加新城市的五条内容：

```json
"国家 · 城市名": [
  {
    "bucket": "世界一角",
    "title": "标题",
    "body": "正文（1-2段）",
    "image": "/assets/images/loc_xxx.png",
    "ponder": "想一想提示（可选，留空字符串则不显示）"
  }
  // ... 另外 4 条，bucket 分别为：科学自然、他人在场、思想火花、旧物新看
]
```

### 启用新城市（使其可被选为目标城市）

在 `public/assets/data/locations.json` 中找到对应城市，将 `hasCustomImages` 设为 `true`，并确认已准备好对应的 5 张插画（`loc_xxx.png` 等）。

也可使用脚本批量标记：

```bash
python3 scripts/mark_custom_locations.py
```

### 验证数据完整性

```bash
python3 scripts/verify_project_data.py
```

会检查 `locations.json` 与 `catalog.json` 的条目数量、名称匹配及内容格式。
